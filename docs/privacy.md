# プライバシー説明

INIAD Plus - MOOCs PDF Helper は、INIAD MOOCs の認可済み講義ページで配信されている Google Slides 資料を利用者自身の学習用 PDF として印刷保存しやすくし、講義ページの課題・出席確認を補助する非公式ブラウザー拡張です。

## 収集しない情報

- 氏名、メールアドレス、学籍情報などの個人情報
- 閲覧履歴や行動ログ
- 位置情報
- 認証情報やパスワード
- 解析・広告・トラッキング用データ

## 保存する情報

Chrome Web Store 配布版の拡張機能自体は、ユーザーデータを保存しません。

利用者が Chrome の印刷ダイアログから PDF として保存した場合、そのファイルは利用者が選んだローカル保存先に作成されます。開発者はそのファイルを取得できません。

Firefox Add-ons 配布版は、学習補助機能のために、利用者が入力したメモ、アップロードした時間割 JSON、履修クラス設定、表示設定を moocs.iniad.org のブラウザー localStorage にのみ保存します。これらのデータは利用者の端末内に留まり、開発者や第三者へ送信されません。削除は各機能の操作、またはブラウザーのサイトデータ削除で行えます。

## ウェブサイトのコンテンツの取り扱い

- INIAD MOOCs の講義ページや、埋め込まれた Google スライドの表示内容を、PDF 作成機能の実行時にブラウザ内でのみ処理します
- この処理は、利用者が押した PDF 作成ボタンに応じて行われます
- 課題・出席まとめ機能は、課題タブや提出状況の分類のために、同じ講義内のページ（moocs.iniad.org の同一オリジン）を利用者のログイン状態で自動取得し、ブラウザー内でのみ解析します。取得した内容は表示補助にのみ使用し、保存も外部送信もしません
- 取得した内容は PDF の生成と画面表示のためだけに使われ、開発者の外部サーバーへ送信されません
- ログイン制限、アクセス制限、ダウンロード制限を回避する機能はありません。利用者が正当に閲覧できる資料だけを対象にします

## 外部送信

INIAD Plus は、開発者が管理する外部サーバーへデータを送信しません。

PDF 保存機能では、表示中の Google スライドの内容をブラウザ内で印刷用ページに整形します。Chrome Web Store 配布版では自動ダウンロードを行わず、利用者が Chrome の印刷ダイアログから PDF として保存します。

この拡張機能による情報の利用は、Chrome Web Store User Data Policy の Limited Use requirements に従います。取得したウェブページ内容や PDF 作成用データは、利用者向けの学習用 PDF 作成機能と課題・出席まとめ機能を提供する目的にのみ使用します。

Firefox Add-ons 配布版では、取得したページ内容を、学習用 PDF 作成と上記の学習補助機能（メモ・時間割・課題タブ分類などの表示補助）の提供にのみ使用します。

## 必要な権限について

Chrome Web Store 配布版の `manifest.json` は、拡張機能の `permissions`、`optional_permissions`、background service worker を要求しません。

提出版では `debugger`、`downloads`、`storage` 権限を使用しません。
