# Output Checklist: INIAD Plus - MOOCs PDF Helper

Before answering or reporting:

- State what was actually verified.
- Separate local seed evidence from live/current-state evidence.
- Mention unknowns or stale assumptions.
- Keep secrets, credentials, customer data, and private rows out of the answer.
- If making code changes, run the smallest relevant verification first, then broaden when shared behavior is touched.
